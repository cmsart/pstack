**Our active library is `agent-workflows/`. These adaptations are new composed files, not a wholesale replacement of the upstream plugin.

## Deliberate departures

1. **Evidence over reviewer count.** Upstream interrogate prioritizes multi-model agreement. Our acceptance policy preserves every reproducible required-behavior failure, including a lone finding. Disagreement triggers replay; it cannot turn a failure into a majority pass.
2. **Coverage over an empty findings list.** A code review may legitimately return no findings. Browser acceptance must account for every required criterion and attach actual observations.
3. **Separate discovery inputs.** The implementer has source-informed recipes; the initial validator gets the approved spec and environment mechanics, not the implementer's recommended journeys or conclusions.
4. **Fixed rules during a run.** Maintenance and reflection can produce useful changes, but active acceptance remains bound to its original specification, skill and harness versions.
5. **Smaller default workflow.** We did not activate Poteto Mode, Arena, Swarm, or a standing coordinator tree. Extra agents can be added when an authorized task warrants them.
6. **Portable instructions.** Cursor-specific model IDs, Task arguments, transcript discovery, rules paths and automatic external actions were removed from the adapted entrypoints.
7. **Honest readiness.** The skills are authored and statically checked. E2B/browser/provider wiring, executable gates, and live model evaluations are still to implement.

Open the source link in the left column and our skill in the second column. Source links are immutable upstream snapshots; our links resolve within this checkout/fork. For the closest one-to-one comparisons, start with bootstrap and maintenance. The validator is the largest new composition, so read the runtime contract before comparing it with interrogate.

When updating upstream later, inspect changes against the pinned revision and promote selected ideas deliberately. Do not automatically overwrite our contract or preserve an old acceptance result across a changed skill version.
